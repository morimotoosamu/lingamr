# Validate the return value of a `cd_fit` function

Validate the return value of a `cd_fit` function

## Usage

``` r
validate_cd_fit_output(cd_res, p, n_datasets)
```

## Arguments

- cd_res:

  Return value of `cd_fit(X_list)`

- p:

  Number of features

- n_datasets:

  Expected number of adjacency matrices (= number of imputed datasets)
