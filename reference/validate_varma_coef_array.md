# Validate a user-supplied VARMA coefficient array

Validate a user-supplied VARMA coefficient array

## Usage

``` r
validate_varma_coef_array(coefs, n_features, arg_name)
```

## Arguments

- coefs:

  candidate array

- n_features:

  number of variables in X

- arg_name:

  argument name for error messages

## Value

the array, with dimensions checked
