# Convert a MultiGroupBootstrapResult to a tidy data.frame

Stacks each group's causal direction counts (via
[`get_causal_direction_counts()`](https://morimotoosamu.github.io/lingamr/reference/get_causal_direction_counts.md))
into a single data.frame with a `group` column in front. Arguments for
[`get_causal_direction_counts()`](https://morimotoosamu.github.io/lingamr/reference/get_causal_direction_counts.md)
can be passed through `...`.

## Usage

``` r
# S3 method for class 'MultiGroupBootstrapResult'
tidy(x, ...)
```

## Arguments

- x:

  The return value of
  [`lingam_multi_group_bootstrap()`](https://morimotoosamu.github.io/lingamr/reference/lingam_multi_group_bootstrap.md)
  (a `MultiGroupBootstrapResult` object)

- ...:

  Arguments passed to
  [`get_causal_direction_counts()`](https://morimotoosamu.github.io/lingamr/reference/get_causal_direction_counts.md)
  (such as `n_directions`, `min_causal_effect`,
  `split_by_causal_effect_sign`)

## Value

data.frame (group, from, to, count, proportion, ...)
