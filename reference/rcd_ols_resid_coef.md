# OLS residual and coefficients (with intercept)

OLS residual and coefficients (with intercept)

## Usage

``` r
rcd_ols_resid_coef(y, X_exog)
```

## Arguments

- y:

  response vector

- X_exog:

  explanatory-variable matrix (may have 0 columns)

## Value

list(resid = residual vector, coef = coefficient vector excluding
intercept)
