# Independence judgment used throughout RCD (hsic or fcorr)

Independence judgment used throughout RCD (hsic or fcorr)

## Usage

``` r
rcd_is_independent(a, b, independence, ind_alpha, ind_corr)
```

## Arguments

- a:

  numeric vector

- b:

  numeric vector

- independence:

  "hsic" or "fcorr"

- ind_alpha:

  significance level (hsic only)

- ind_corr:

  rejection threshold (fcorr only)

## Value

TRUE if independent
